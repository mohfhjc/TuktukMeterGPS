# TukTuk Escape

نسخة أولية من لعبة 3D خفيفة للموبايل.

## الموجود حاليا
- مدينة بسيطة 3D
- لاعب وتحكم WASD
- تحكم لمس مبدئي بعصا افتراضية
- كاميرا خلف اللاعب
- سيارات
- عملات
- مال وصحة
- أول مهمة
- GitHub Actions لبناء APK

## الخطوة التالية
إضافة شخصية أفضل، توك توك قابل للقيادة، شرطة ومطاردة، متجر، مراحل، مؤثرات صوتية وتحسين الرسوم مع الحفاظ على حجم قريب من 50MB.
